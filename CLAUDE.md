## Project journal (Obsidian)

This project has a companion note in my Obsidian vault:
`~/Documents/Triad Solutions/ProjectVault/01 Projects/MenuApp/MenuApp.md`

Follow these rules for it:

- **At the start of every session**, read the vault note — the frontmatter
  (`status`, `next-action`) and the most recent entries under `## 🗒️ Log` — for
  context on where work left off.
- **After completing significant work** (a feature is done, a decision is made, a
  blocker is hit), append a dated entry under `## 🗒️ Log` — 1–3 bullets covering
  what was done and why. Use an `### YYYY-MM-DD` heading; add bullets under
  today's heading if it already exists.
- **Keep the frontmatter current**: update `next-action` to the single most
  important next step, and update `status` (`active` / `on-hold` / `done`) when it
  changes.
- **Never rewrite or delete existing log entries** — only append.
- **Don't log trivial changes** (typos, formatting, minor refactors).
